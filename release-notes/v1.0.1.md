Maintenance release.

- The download package is now smaller: it contains only the files the extension needs to run, plus the README, LICENSE and `INSTALL.txt`. Setup guides, examples and the KBMax API notes stay in the repository.
- Releases are now published by a GitHub Actions workflow when a version tag is pushed.

Install: download **KBMax-Backup-v1.0.1.zip**, unzip it, open `edge://extensions` (or `chrome://extensions`), enable **Developer mode**, click **Load unpacked** and select the unzipped folder.
