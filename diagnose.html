Access diagnostics

-
This only reads. It looks in the KBMax tab for the place where the logged-in user is stored, lists the calls the page itself made while loading (names only), and tests which calls this user may make. For the best result, reload the KBMax page first and run the diagnostics straight after. Tokens and long values are never shown. The report can contain your own name and e-mail address: check it before you share it.
